# WeAct Studio STM32H743VITX ToF

이 프로젝트는 WeAct Studio의 STM32H743VITX 보드를 활용하여 제작된 ToF(Time-of-Flight) 센서 테스트 코드입니다.
## 하드웨어 참조 링크
* [WeAct Studio AliExpress Store](https://weactstudio.ko.aliexpress.com/store/910567080?spm=a2g0o.detail.0.0.55c9v8gBv8gB7I)

## 주요 하드웨어 구성
* **MCU**: STM32H743VITX (고성능 ARM Cortex-M7)
* **ToF 센서**: VL53L0X (적외선 레이저 기반 정밀 거리 측정)
* **디스플레이**: ST7789 TFT LCD (디버깅 및 상태 출력용)
